# Report checklist

## 数据与研究

- [ ] 公司类型和估值框架匹配
- [ ] 当前价格与适用日期已核验
- [ ] 最新财报来自公司 IR、SEC 或其他一手来源
- [ ] 收入、利润、现金流、现金、债务和稀释股本口径一致
- [ ] 下一次财报日期区分已公告与估计
- [ ] 事实、估算、推理和情景假设已区分

## 估值

- [ ] 关键输入、公式和计算过程可追溯
- [ ] Bear/Base/Bull 或周期情景完整
- [ ] 使用至少一种交叉估值方法
- [ ] 分部利润为估算时说明方法与误差
- [ ] 买入/减仓区间与估值结果一致
- [ ] 抄底区间注明基本面前提

## HTML 与发布

- [ ] 文件位于 reports/ 且命名正确
- [ ] 顶部适用日期、公司和数据口径完整
- [ ] 返回首页链接为 ../index.html
- [ ] index.html 已新增报告入口
- [ ] 不包含本机绝对路径
- [ ] 所有本地链接目标存在
- [ ] 外部来源使用 HTTPS
- [ ] 移动端基本可读
- [ ] 已运行 python3 scripts/validate_reports.py
- [ ] Git diff 只包含本次变更
- [ ] 推送后抽查 GitHub Pages
