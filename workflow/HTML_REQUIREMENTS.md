# HTML requirements

## 页面要求

- HTML5、UTF-8，桌面和移动端可读。
- 顶部显示：研报适用日期：YYYY-MM-DD ｜ 公司：SYMBOL ｜ 数据口径：最新财报季度。
- 顶部返回首页链接使用 ../index.html。
- 文件名为 reports/SYMBOL_Research_YYYYMMDD.html。
- 页面包含清晰表格、来源链接和风险提示，不依赖本机绝对路径或登录态资源。

## 必备内容

- 当前价格的来源与时间点
- 最新财报口径、稀释股本、现金和债务
- 核心估值、关键假设和计算过程
- Bear/Base/Bull 或相符的周期情景
- 现金流、风险、催化剂和跟踪指标
- 完整仓位区间，并注明仅在基本面没有破坏时成立
- 下一次财报日期；未正式公告时标注为估计
- 主要一手来源链接

## 首页要求

- 根目录 index.html 的首要内容是报告目录。
- 新报告按日期倒序加入。
- 报告链接使用 reports/文件名.html。
- 常用工具只保留真正可跳转的入口。
